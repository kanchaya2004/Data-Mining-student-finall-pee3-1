บท 6 การประเมินผลโมเดล เน้นสุด

ประเมินโมเดลเพื่ออะไร

เพื่อเช็กว่าโมเดลดีพอจะนำไปใช้งานจริงหรือยัง โดยดูจากความแม่นยำและความถูกต้อง Confusion Matrix เป็นตารางหลักที่ใช้วัดโมเดลแบบ classification

Confusion Matrix (ตามสไลด์)

Predicted \ ActualPositiveNegative
PositiveTPFP
NegativeFNTN

แถว = ผลที่โมเดลทำนาย, คอลัมน์ = ค่าจริง

ความหมายแต่ละช่อง

  • TP ทายว่าใช่ แล้วใช่จริง (Hit)
  • TN ทายว่าไม่ใช่ แล้วไม่ใช่จริง (Correct Rejection)
  • FP ทายว่าใช่ แต่จริงไม่ใช่ (False Alarm, Type I error)
  • FN ทายว่าไม่ใช่ แต่จริงใช่ (Miss, Type II error)
  • Condition Positive (P) = TP + FN, Condition Negative (N) = FP + TN

สูตร 4 ตัว (ออกสอบแน่นอน)

Precision = TP / (TP + FP)
Recall = TP / (TP + FN)
Accuracy = (TP + TN) / (TP + TN + FP + FN)
F-measure = 2 × (Precision × Recall) / (Precision + Recall)
วิธีจำ ตัวหารของ Precision คือ ทุกอันที่โมเดลทายว่า Positive (แถวบน TP+FP) ตัวหารของ Recall คือ Positive จริงทั้งหมด (คอลัมน์ซ้าย TP+FN) Accuracy ดูทุกคลาสรวมกัน ส่วน Precision, Recall, F-measure ดูแยกทีละคลาส
  • Precision วัดความแม่นยำของผลทำนาย พิจารณา TP เทียบ FP
  • Recall วัดว่าเก็บของจริงได้หมดแค่ไหน พิจารณา TP เทียบ FN
  • F-measure คือค่าเฉลี่ยของ Precision และ Recall ใช้ดูทั้งสองค่าพร้อมกัน
  • Accuracy จำนวนที่ทายถูก หารจำนวนที่ทายทั้งหมด

Decision Tree ความรู้ทั่วไป

โครงสร้าง

  • Root node จุดเริ่มต้น เลือก attribute ที่แบ่งข้อมูลได้ดีที่สุด
  • Internal node ทดสอบค่า attribute
  • Branch ผลของการทดสอบ
  • Leaf node คลาสคำตอบ

เป็นการเรียนรู้แบบมีผู้สอน (supervised) อ่านผลออกมาเป็นกฎ if-then ได้

เกณฑ์เลือก attribute

Entropy = − Σ p·log₂(p)
Gain = Entropy(เดิม) − Entropy(หลังแบ่ง)
  • Gain สูงสุด ได้เป็นโหนดถัดไป (ID3)
  • Entropy = 0 คือโหนดบริสุทธิ์ (คลาสเดียว)
  • Entropy = 1 คือสองคลาสเท่ากัน 50:50
  • CART ใช้ Gini index, C4.5 ใช้ Gain Ratio

Overfitting และ Pruning

ต้นไม้ที่ลึกเกินไปจะจำข้อมูลสอนมากเกินจนทำนายข้อมูลใหม่แย่ลง (overfitting) แก้โดยตัดแต่งกิ่ง (pruning) หรือจำกัดความลึก ตัวอย่าง Entropy ของ Play golf (yes 9, no 5) = 0.940

บท 7 Naive Bayes ท่องสูตร

แนวคิด

  • ทฤษฎีของ Thomas Bayes เป็นการเรียนรู้แบบมีผู้สอน อาศัยความน่าจะเป็นคาดเดาสิ่งที่ยังไม่เคยเกิดจากสิ่งที่เคยเกิดมาก่อน
  • เป็นอัลกอริทึมไม่ซับซ้อน สร้างโมเดลง่าย
  • เรียกว่า “Naive” เพราะสมมติให้แอตทริบิวต์เป็นอิสระต่อกัน เมื่อรู้คลาสแล้ว
P(C|A) = P(A|C) × P(C) / P(A)
Posterior P(C|A)
โอกาสที่ข้อมูลที่มีแอตทริบิวต์ A จะเป็นคลาส C
Likelihood P(A|C)
โอกาสที่ข้อมูลสอนคลาส C มีแอตทริบิวต์ A
Prior P(C)
ความน่าจะเป็นของคลาส C ที่ทราบมาก่อน
P(A)
ความน่าจะเป็นของเหตุการณ์ A (ตัวหาร ใช้เทียบคลาสเท่ากัน จึงตัดทิ้งได้)

Conditional probability: P(A|B) = P(A∩B) / P(B)

บท 8 Association Rule Support / Confidence

แนวคิด

  • หาความสัมพันธ์ของข้อมูลจากรูปแบบที่เกิดร่วมกันบ่อย (frequent pattern) มักใช้กับค้าปลีก เรียก Market Basket Analysis
  • ใช้จัดวางสินค้าบนชั้น ทำโปรโมชัน และทำแคตตาล็อก
  • ฐานข้อมูลเป็น Transaction Database ข้อมูลเป็น Nominal หรือ Ordinal
  • รูปแบบกฎ LHS ⇒ RHS LHS คือส่วนก่อน (เหตุ) RHS คือส่วนหลัง (ผล)
  • สินค้า N ชนิด มีชุดสินค้าที่เป็นไปได้ 2N − 1 รูปแบบ (3 ชนิด = 7)

Apriori มี 2 ขั้นตอนใหญ่

  1. หา Frequent Itemsets คือชุดสินค้าที่ support ไม่ต่ำกว่า minimum support มี 2 ขั้นย่อย: join (สร้างชุดที่ยาวขึ้นทีละหนึ่ง) และ count support
  2. สร้าง Association Rule จาก frequent itemsets ที่ผ่าน minimum confidence
Support(Itemset) = จำนวน transaction ที่ปรากฏ / จำนวน transaction ทั้งหมด
Confidence(LHS ⇒ RHS) = Support(LHS, RHS) / Support(LHS)

Support

วัดความนิยมของชุดสินค้า เทียบกับ transaction ทั้งหมด

Confidence

วัดความน่าเชื่อถือของกฎ เทียบกับเฉพาะ transaction ที่มี LHS

กฎที่ดีต้องผ่านทั้ง Minimum Support และ Minimum Confidence ซึ่งผู้เชี่ยวชาญเป็นคนกำหนด
